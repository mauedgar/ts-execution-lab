# Execution Surface v0

Initial routing rule:

- Commander/local: bounded local execution when Windows/local state/tools are required.
- GitHub Actions: reproducible clean Ubuntu execution, exact-subject validation, deterministic transformations, freeze/receipt generation, and other qualified remote mechanics.
- GitHub repo/artifact: durable transport/result surface.
- ChatGPT Web: semantic determination, adaptive wait/observation, and semantic adjudication.
- Either executor may later be a fallback for the other ONLY for profiles proven semantically equivalent across both environments.
- fallback means same logical operation, NEW ExecutionAttempt, preserved exact request/profile identity, no blind retry after ambiguous effect.
- no arbitrary remote shell interface in v0.

This is a DevLab experiment with authority NONE.

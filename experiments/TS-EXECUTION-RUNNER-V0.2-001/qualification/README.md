# Worker C Qualification Fixtures

These fixtures define the evidence inputs and expected identities for the v0.2
qualification pass. They are preparation artifacts, not execution evidence.

- `matrix.json` maps every work-package DoD to its required proof and status.
- `local-remote-equivalence.json` fixes one canonical request and expected
  local/remote correspondence.
- `fallback-proof.json` fixes the safe Attempt A / new Attempt B relationship.

No fixture asserts that an unexecuted v0.2 proof passed.

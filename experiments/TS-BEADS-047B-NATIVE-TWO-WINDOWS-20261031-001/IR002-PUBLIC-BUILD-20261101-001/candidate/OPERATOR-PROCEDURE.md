2. Independently capture native Dolt **2.2.0** version/help evidence for `CREATE USER`, `DROP USER`, `GRANT`, parameter binding and the passwordless `root@localhost` behavior. Without it, retain `BLOCKED_PINNED_SQL_GRAMMAR_UNVERIFIED`.
3. Install and verify an approved in-memory `MySqlConnector` dependency. Do not substitute `dolt sql`, `-e`, a shell, environment password, transcript, or argument password.
4. Run only preflight first using the real provider. It must prove the approved Windows host/owner, peer, binaries, vacant port, no SQL/Serve/Funnel, absent/reconciled isolated root, ACL, no prior/UNKNOWN write and source integrity.
5. A separately authorized caller may invoke `Apply`. It writes no secrets to receipts, starts only `127.0.0.1:3307`, creates a recovery admin before removing passwordless root, and does **not** enable Serve.
6. If any effect is partial or unknown, preserve state and the original receipt. Do not retry, rollback, cleanup, or enable ingress. Tailscale Serve remains a separately reviewed operation.
